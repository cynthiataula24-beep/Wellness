# Wellness App: Holistic Health Tracker
This project is a comprehensive wellness application designed to help users monitor their daily health metrics and mental well-being. It leverages a modern mobile frontend with a robust Python backend to provide a seamless user experience.

# Features
User Authentication: Secure login and registration system.

Health Dashboard: Real-time tracking of wellness goals.

Data Synchronization: Seamless communication between the Android client and the Flask server.

JSON-based API: Efficient data handling using a custom-built REST API.

# Tech Stack
Frontend: Kotlin 

Backend: Python - Flask

Database: SQLAlchemy

Architecture: MVC (Model-View-Controller)
